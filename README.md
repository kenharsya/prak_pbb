## Fitur Utama
1. **Katalog Novel Pastel**: Menampilkan daftar novel Indonesia & Inggris dengan kartu warna pastel secara dinamis.
2. **Pencarian Real-Time**: Fitur pencarian buku berdasarkan judul dan kategori secara responsif.
3. **Halaman Detail**: Menampilkan sampul buku, harga, kategori, dan deskripsi lengkap saat produk dipilih.
